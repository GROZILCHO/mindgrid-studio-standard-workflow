# General Project Starter Kit

Status: Draft

## Purpose

This starter kit is the neutral base for any MindGrid Studio project when the technical platform is not yet fully decided.

Use it for:

- Early project discovery.
- Project planning.
- Non-code project documentation.
- Strategy-first website projects.
- Projects that may later become React/Vite, WordPress, or another platform.

## When To Use This Starter Kit

Use the general starter when the project needs structure before platform decisions are final. It is the right starting point when the team still needs to define the business goal, site structure, content model, technical direction, or asset needs.

Use a platform-specific starter instead when the project is already confirmed as React/Vite or WordPress and the implementation constraints are known.

## What It Contains

- AGENTS.md: operating rules for Codex and assistant agents.
- docs/PROJECT_BRIEF.md: business context, audience, goals, and constraints.
- docs/PROJECT_RULES.md: project rules, file scope, claims, content, and technical constraints.
- docs/SITE_STRUCTURE.md: pages, routes, navigation, and information architecture.
- docs/CONTENT_MODEL.md: page content, reusable blocks, and content dependencies.
- docs/DESIGN_SYSTEM.md: visual direction, typography, color, layout, and component notes.
- docs/SEO_PLAN.md: SEO/AEO planning, metadata, indexing, and launch notes.
- docs/IMAGE_ASSET_REGISTER.md: source images, optimized images, usage, alt text, and status.
- docs/QA_CHECKLIST.md: project QA checks.
- docs/CURRENT_STATUS.md: current phase, progress, git status, validation, and handoff notes.
- docs/NEXT_ACTIONS.md: concrete next tasks.
- docs/ISSUES_LOG.md: bugs, blockers, risks, and unresolved questions.
- docs/DECISIONS_LOG.md: real strategic, technical, content, SEO, design, or workflow decisions.
- docs/PROJECT_HANDOFF.md: context for switching chats, agents, or phases.
- docs/DEPLOYMENT_GUIDE.md: deployment process and release notes.

## First Project Steps

1. Create project repository.
2. Copy the general starter kit.
3. Fill PROJECT_BRIEF.md.
4. Fill PROJECT_RULES.md.
5. Draft SITE_STRUCTURE.md.
6. Decide technical platform.
7. Switch to React/Vite or WordPress starter workflow if needed.
8. Activate Codex only after basic documents are ready.

## Stop Conditions

Stop and clarify before implementation if:

- No project owner.
- Unclear project type.
- No repository.
- No brief.
- Unclear business goal.
- Unclear access/credentials.
- Unclear next technical direction.
