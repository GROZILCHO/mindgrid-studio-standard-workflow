## Severity Guide

- Critical: blocks launch, breaks core functionality, affects data, or creates serious production risk.
- High: affects important user flows, SEO, performance, deployment, admin access, or delivery.
- Medium: should be fixed before final release but does not block all work.
- Low: cosmetic, documentation, minor UX, or future polish.

## Update Rules

- Keep issue descriptions factual.
- Update status as issues are resolved, deferred, or replaced.
- Link related next actions, decisions, files, tasks, backups, exports, or validation output when useful.
