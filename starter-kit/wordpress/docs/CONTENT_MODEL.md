# Content Model

Status: Draft

## Purpose

Defines repeatable content structures for WordPress page types before writing, page building, content entry, or migration begins.

## Usage Notes

- Content may live in WordPress database, page builder fields, custom fields, posts, pages, products, or reusable blocks.
- Structure and ownership must be documented before content entry.
- Mark uncertain claims for review.

- No fake metrics.

- No fake certifications.
- No fake case studies.
- No unverifiable partnerships.
- Mark uncertain claims for review.
