# React/Vite Project Starter Kit

Status: Draft

## Purpose

This starter kit is used when the project will be built as a React/Vite site, static/prerendered website, SEO-oriented company site, or similar file-based project.

## When To Use

Use this starter for:

- React/Vite websites.
- Static/prerendered sites.
- SEO-oriented company websites.
- Landing systems.
- Projects where GitHub can hold nearly the full source of truth.

## What To Add After Copying

Copy this starter kit into a real project repository, then combine it with actual project files:

- package.json
- Vite config
- React entry files
- components
- pages
- seo config
- scripts
- assets
- styles

Do not include these files in the workflow repo starter unless intentionally building a real starter app later.

## Required Docs Before Implementation

## First Implementation Sequence

1. Fill brief and rules.
2. Define route map.
3. Define content model.
4. Define design system.
5. Define asset system.
6. Create or copy React/Vite app files.
7. Assign first Codex implementation task.
8. Run typecheck/build validation.
9. Update tracking docs.
