# Next Actions Template

Status: Draft

## Purpose

Reusable project tracking document for concrete upcoming tasks that should not be lost between ChatGPT, Codex, and Rosen sessions.

## Usage Rules

- Update when there are concrete next steps.
- Keep actions ordered by priority.
- Write each action so it can become the next ChatGPT planning prompt or Codex implementation task.
- Do not use this file as a daily changelog.
- Remove, revise, or archive stale actions after they are completed or replaced.
- Link related issues or decisions when useful.

## Status Values

- Pending
- In Progress
- Blocked
- Done
- Deferred

## Priority Values

- High
- Medium
- Low

## Template Structure

| Priority | Action | Owner | Status | Dependency | Suggested Next Prompt/Task |
| --- | --- | --- | --- | --- | --- |
| High | Placeholder action | Rosen / ChatGPT / Codex | Pending | Placeholder dependency or none | Placeholder next prompt or task |

## Notes

- High priority: define the next task that moves the project forward.
- Medium priority: capture useful follow-up work that is not blocking.
- Low priority: capture cleanup, documentation, or later optimization work.

## Maintenance Notes

- Codex should update this file only when requested or when a task creates clear follow-up actions.
- ChatGPT Lead Assistant may use this file to prepare the next Codex task.
- Rosen may use this file to choose the next project priority.
