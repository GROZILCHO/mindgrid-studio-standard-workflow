# Content Model

Status: Draft

## Purpose

This document defines repeatable content structures for page types before writing or implementation begins.

## Usage Notes

- Define page structures before writing long copy.
- Keep page purpose, conversion goal, and SEO intent separate.
- Mark uncertain claims for review before implementation.
- Use this model for React/Vite file content and WordPress/CMS content planning.

## 5. Claim Safety Model

- Supported claims only.
- No fake metrics.
- No unsupported response-time promises.
- No fake certifications.
- No fake case studies.
- No unverifiable partnerships.
- Mark uncertain claims for review.
