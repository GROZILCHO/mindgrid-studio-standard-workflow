# Visual QA Checklist

Status: Draft

## Purpose

This checklist is used to review visual consistency, layout quality, and asset usage before release.

## 1. Page-level Visual Review

- [ ] Homepage reviewed.
- [ ] Main overview pages reviewed.
- [ ] Detail pages reviewed.
- [ ] Contact page reviewed.
- [ ] About page reviewed.
- [ ] Legal/simple pages reviewed if present.
- [ ] Mobile views reviewed.
- [ ] Tablet views reviewed.
- [ ] Desktop views reviewed.

## 2. Design System Consistency

- [ ] Colors match the design system.
- [ ] Typography is consistent.
- [ ] Button styles are consistent.
- [ ] Card styles are consistent.
- [ ] Section spacing is consistent.
- [ ] Hero sections follow approved pattern.
- [ ] CTA sections follow approved pattern.
- [ ] Dark/light sections are used consistently.
- [ ] No one-off styles introduced without approval.

## 3. Image And Asset Review

- [ ] Hero images are relevant.
- [ ] Repeated images are intentional.
- [ ] Generic/stock-looking images are avoided where possible.
- [ ] Images are not stretched.
- [ ] Crops work on desktop.
- [ ] Crops work on mobile.
- [ ] AVIF/WebP fallback works if used.
- [ ] Alt text is acceptable.
- [ ] OG images match page intent.
- [ ] No external fallback images unless approved.

## 4. Content/UI Label Review

- [ ] UI labels match the site language.
- [ ] Eyebrows/tags are localized.
- [ ] Metric labels are localized.
- [ ] CTA labels are consistent.
- [ ] No placeholder labels remain.
- [ ] No unsupported promises remain.
- [ ] Technical abbreviations are preserved where appropriate.

## 5. Interaction And Responsive Review

- [ ] Navbar works.
- [ ] Mobile menu works.
- [ ] Dropdowns work.
- [ ] CTA links work.
- [ ] Forms are visually usable.
- [ ] Sticky/fixed elements do not overlap content.
- [ ] No horizontal scroll.
- [ ] No major layout shift.
- [ ] Images do not break layout.

## 6. Stop Conditions

Stop visual approval if:

- [ ] Main hero is broken.
- [ ] Mobile navigation is broken.
- [ ] Major page layout is inconsistent.
- [ ] Key images are missing.
- [ ] Visual system is inconsistent across page clusters.
- [ ] CTA is misleading.
- [ ] Page looks unfinished or placeholder-driven.
- [ ] User-facing language is inconsistent.
