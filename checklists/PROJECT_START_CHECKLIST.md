# Project Start Checklist

Status: Draft

## Purpose

This checklist ensures a new MindGrid Studio project starts with clear structure, documents, roles, and repositories before design or implementation work begins.

## 1. Project Identity

- [ ] Project name is defined.
- [ ] Client / owner is defined.
- [ ] Business context is understood.
- [ ] Primary project goal is defined.
- [ ] Project type is identified: React/Vite, WordPress, WooCommerce, static site, landing page, redesign, or other.
- [ ] Main language and possible future languages are identified.
- [ ] Target launch timeframe is known.
- [ ] High-level risks are noted.

## 2. Workspace Setup

- [ ] GitHub repository exists or will be created.
- [ ] Correct starter-kit type is selected: general, react-vite, wordpress, or other.
- [ ] Notion project entry exists, if Notion will be used.
- [ ] Project folder exists locally.
- [ ] Repository remote is configured.
- [ ] Initial branch is defined.
- [ ] AGENTS.md is present.
- [ ] docs/ folder is present.
- [ ] git status is clean before first implementation task.

## 3. Required Starter Documents

- [ ] PROJECT_BRIEF.md exists.
- [ ] PROJECT_RULES.md exists.
- [ ] SITE_STRUCTURE.md exists.
- [ ] CONTENT_MODEL.md exists.
- [ ] DESIGN_SYSTEM.md exists or is explicitly not needed.
- [ ] SEO_PLAN.md exists or is planned.
- [ ] IMAGE_ASSET_REGISTER.md exists or is planned.
- [ ] CURRENT_STATUS.md exists.
- [ ] NEXT_ACTIONS.md exists.
- [ ] ISSUES_LOG.md exists.
- [ ] DECISIONS_LOG.md exists.
- [ ] PROJECT_HANDOFF.md exists.
- [ ] DEPLOYMENT_GUIDE.md exists or is planned.

## 4. Role Activation

- [ ] Rosen / MindGrid Studio role is confirmed.
- [ ] ChatGPT Lead Assistant role is activated.
- [ ] Codex Developer role is activated only after starter documents are prepared.
- [ ] Optional specialists are identified if needed:
  - [ ] Content Strategist.
  - [ ] Visual Prompt Designer.
  - [ ] SEO/AEO Specialist.
  - [ ] QA/Release Specialist.
  - [ ] Notion Ops Coordinator.

## 5. Pre-strategy Questions

- [ ] Who is the audience?
- [ ] What is the main conversion goal?
- [ ] What pages are likely required?
- [ ] What content exists already?
- [ ] What content is missing?
- [ ] Are there competitor/reference sites?
- [ ] Are there brand rules?
- [ ] Are there existing images/assets?
- [ ] Are there forbidden claims or unsupported promises?
- [ ] Are legal/cookie/analytics requirements expected?

## 6. Stop Conditions

Stop project start and clarify before continuing if any of these apply:

- [ ] No clear project owner.
- [ ] No clear project type.
- [ ] No repository or working folder.
- [ ] No agreed starting documents.
- [ ] Missing access credentials.
- [ ] Unclear deployment target.
- [ ] Unclear content ownership.
- [ ] Unclear deadline.
- [ ] Unclear technology stack.

## 7. Project Start Command

Start a new web project using MindGrid Studio Standard Workflow v1.0. First run Project Intake. Do not propose design, code or implementation before PROJECT_BRIEF.md, SITE_STRUCTURE.md and PROJECT_RULES.md are established.
