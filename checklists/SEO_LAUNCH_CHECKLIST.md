# SEO Launch Checklist

Status: Draft

## Purpose

This checklist is used before and after launch to ensure the site is indexable, crawlable, and technically prepared for search visibility.

## 1. Indexing Basics

- [ ] Public pages are not accidentally noindexed.
- [ ] Draft/private pages are not indexed.
- [ ] Canonical URLs are correct.
- [ ] Sitemap is available.
- [ ] Robots.txt is available.
- [ ] Old URLs are redirected if needed.
- [ ] 404 page is intentional.

## 2. Metadata

- [ ] Each key page has a unique title.
- [ ] Each key page has a useful meta description.
- [ ] H1 is present and unique.
- [ ] Open Graph title/description/image are valid.
- [ ] Image URLs resolve.
- [ ] Language consistency is checked.
- [ ] Brand name usage is consistent.

## 3. Content Quality

- [ ] Page purpose is clear.
- [ ] Main CTA is clear.
- [ ] No unsupported claims.
- [ ] No placeholder text.
- [ ] No mixed-language UI labels unless intentional.
- [ ] Internal links support the site structure.
- [ ] Service/product/industry pages have enough context.

## 4. Technical SEO

- [ ] Sitemap contains only canonical public URLs.
- [ ] Robots.txt does not block public content.
- [ ] Structured data is valid if used.
- [ ] Pagination/filtering rules are defined if relevant.
- [ ] Redirects are tested.
- [ ] SSL works.
- [ ] Mobile rendering is acceptable.
- [ ] Page speed is acceptable for launch.

## 5. Search Console / Analytics

- [ ] Google Search Console property created.
- [ ] Sitemap submitted.
- [ ] Ownership verified.
- [ ] Analytics/Tag Manager installed if approved.
- [ ] Cookie consent implemented if tracking requires it.
- [ ] Key conversion events defined if needed.

## 6. Post-launch Monitoring

- [ ] Check indexing after launch.
- [ ] Check crawl errors.
- [ ] Check 404 reports.
- [ ] Check Core Web Vitals.
- [ ] Check search performance trends.
- [ ] Update NEXT_ACTIONS.md with SEO follow-up tasks.
- [ ] Update ISSUES_LOG.md if search/indexing issues appear.

## 7. Stop Conditions

Do not submit for indexing if:

- [ ] Public pages are noindexed accidentally.
- [ ] Sitemap is broken.
- [ ] Robots.txt blocks the site.
- [ ] Canonicals are wrong.
- [ ] Major pages have placeholder content.
- [ ] Major pages have broken images or links.
- [ ] Tracking/cookie consent is legally required but unresolved.
