# MindGrid Studio Standard Workflow

## Purpose

This repository is the reusable workflow and starter documentation system for MindGrid Studio web projects.

Status: Draft

## What This Repository Is

MindGrid Studio Standard Workflow v1.0 defines a repeatable project operating system for planning, documenting, implementing, validating, launching, and reviewing web projects.

It is documentation-first. It does not contain application code, website code, package dependencies, generated assets, or platform-specific builds.

## How It Is Used

Use this repository as the source workflow when starting a new project. Copy or adapt the relevant starter-kit files, templates, prompts, checklists, and platform notes into the real project repository.

## Relationship Between Rosen, ChatGPT, and Codex

- Rosen / MindGrid Studio is the project owner and operator.
- ChatGPT Lead Assistant supports strategy, planning, QA guidance, and Codex task preparation.
- Codex implements narrow tasks through repository files and reports changes, validation, risks, and git status.

## Where To Start

Start with workflow/MINDGRID_STUDIO_STANDARD_WORKFLOW_v1.0.md, then use 	emplates/PROJECT_BRIEF.template.md and checklists/PROJECT_START_CHECKLIST.md.
