# Mall Agro Redesign PMO v2 Project Instance

This folder is the compact central PMO context package for Mall Agro Redesign.

It records operational continuity, project philosophy, guardrails, accepted decisions, current state, workstreams, repository links, risks, and the next safe task. It does not duplicate the Mall Agro application repository.

## Project Identity

| Field | Value |
| --- | --- |
| Project name | Mall Agro Redesign |
| Project type | Next.js App Router B2B equipment catalog and inquiry gateway |
| Technology | Next.js App Router, JavaScript, React, Tailwind CSS |
| Business purpose | Present agriculture, grain processing/handling, and food industry equipment as qualified B2B inquiry paths. |
| Primary audiences | Agricultural businesses, grain processors/handlers, food industry operators, procurement teams, operations managers, technical buyers. |
| Language/domain model | `mallagro.com` for English and `mallagro.ro` for Romanian. Domain-based localization is approved; `/ro` route-prefix model is not approved. |

## What This Instance Is

- Central PMO continuity package for ChatGPT and Codex sessions.
- Compact source of operational status, risks, accepted decisions, and next actions.
- Project-level guardrail summary for PM Assistant / Project Lead use.
- A pointer to detailed evidence in the application repository.

## What This Instance Is Not

- It is not application source code.
- It is not a mirror of `GROZILCHO/mall-agro-redesign`.
- It is not the full editorial, route, or technical documentation set.
- It is not proof that uncommitted application work has been validated.
- It is not a place for secrets, credentials, tokens, private access data, or durable local-machine requirements.
