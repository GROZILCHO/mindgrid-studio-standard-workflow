# Phase 06: Design System

Status: Draft

## Purpose

Define visual direction, color system, typography, spacing/layout rules, component rules, responsive behavior, and accessibility basics before UI implementation.

## When To Use This Phase

Use this phase after content structure is known and before visual implementation, component work, or page building.

## Main Questions

- What visual direction supports the project?
- What color and typography rules are approved?
- What spacing/layout rules must be followed?
- What components are needed?
- What responsive behavior is expected?
- What accessibility basics apply?
- What design drift must be prevented?

## Required Inputs

- PROJECT_BRIEF.md.
- PROJECT_RULES.md.
- SITE_STRUCTURE.md.
- CONTENT_MODEL.md.
- Brand/design materials if available.

## Expected Outputs

- DESIGN_SYSTEM.md.
- Component rules.
- Responsive rules.
- Accessibility/basic usability notes.
- DECISIONS_LOG.md entries where real design decisions are made.

## Recommended Steps

1. Define design direction.
2. Define color system.
3. Define typography system.
4. Define spacing and layout rules.
5. Define component rules.
6. Define responsive behavior.
7. Define accessibility basics.
8. Add design QA checklist.

## Codex / Agent Involvement

- ChatGPT Lead Assistant coordinates design rules.
- Visual Prompt Designer may support asset/visual direction.
- Codex should not invent design tokens or one-off components.

## Tracking Docs Update Rules

- Update CURRENT_STATUS.md after DESIGN_SYSTEM.md is usable.
- Update NEXT_ACTIONS.md with asset/component tasks.
- Update ISSUES_LOG.md for missing brand/design decisions.
- Update DECISIONS_LOG.md for real visual/design system decisions.

## Completion Criteria

- DESIGN_SYSTEM.md is usable for implementation.
- Visual rules are specific enough to prevent drift.
- Responsive and accessibility basics are documented.

## Stop Conditions

- Design direction is unclear.
- Colors/typography are not approved.
- Component rules are missing for implementation.
- Mobile behavior is unknown.
- Visual drift risk is high.

## Handoff Notes

New sessions should inspect DESIGN_SYSTEM.md, CONTENT_MODEL.md, IMAGE_ASSET_REGISTER.md if started, and CURRENT_STATUS.md.
