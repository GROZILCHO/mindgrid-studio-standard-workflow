# Phase 04: Site Structure

Status: Draft

## Purpose

Define the route/page map, navigation, footer, page clusters, page intent matrix, redirects, sitemap rules, and public/private/noindex rules before implementation.

## When To Use This Phase

Use this phase after strategy and positioning are clear and before content modeling, SEO implementation, or page building.

## Main Questions

- What pages/routes are required?
- What navigation structure is approved?
- What footer links are required?
- What page clusters exist?
- What is each page's audience, goal, and CTA?
- Are legacy URLs or redirects involved?
- Which pages are public, private, noindex, or excluded from sitemap?

## Required Inputs

- PROJECT_BRIEF.md.
- PROJECT_RULES.md.
- Strategy/positioning decisions.
- Known SEO direction.
- Existing site URLs if redesign.

## Expected Outputs

- SITE_STRUCTURE.md completed enough for implementation.
- Route/page map.
- Navigation/footer model.
- Redirect/legacy route table.
- Sitemap and indexing rules.
- NEXT_ACTIONS.md updated with content/model tasks.

## Recommended Steps

1. List all required pages.
2. Group pages into clusters.
3. Define route/URL/slug model.
4. Define navigation and footer links.
5. Fill page intent matrix.
6. Identify redirects/legacy URLs.
7. Define sitemap and noindex rules.
8. Run route QA review before implementation.

## Codex / Agent Involvement

- ChatGPT Lead Assistant coordinates site architecture.
- SEO/AEO Specialist may review SEO intent and sitemap rules.
- Codex may audit route consistency but should not invent routes.

## Tracking Docs Update Rules

- Update CURRENT_STATUS.md after SITE_STRUCTURE.md is usable.
- Update NEXT_ACTIONS.md with content/design/SEO tasks.
- Update ISSUES_LOG.md for unresolved route or redirect questions.
- Update DECISIONS_LOG.md for real route/navigation decisions.

## Completion Criteria

- SITE_STRUCTURE.md contains approved routes/pages.
- Navigation and footer are defined.
- Sitemap/noindex rules are clear.
- Redirect needs are documented.

## Stop Conditions

- Route structure is unclear.
- Legacy URL mapping is missing for redesign.
- SEO/public-private rules are unclear.
- Navigation decisions are not approved.

## Handoff Notes

New sessions should inspect SITE_STRUCTURE.md, SEO_PLAN.md, CURRENT_STATUS.md, NEXT_ACTIONS.md, and DECISIONS_LOG.md.
