# Phase 05: Content System

Status: Draft

## Purpose

Define the content model, page type structures, CTA model, metadata needs, internal linking model, localization rules, and claim safety before writing or implementation.

## When To Use This Phase

Use this phase after site structure is defined and before large-scale copywriting, page building, or component implementation.

## Main Questions

- What content belongs on each page type?
- What sections repeat across pages?
- What CTAs are approved?
- What metadata is needed?
- What internal links support the site structure?
- What language/localization rules apply?
- Which claims require approval?

## Required Inputs

- PROJECT_BRIEF.md.
- PROJECT_RULES.md.
- SITE_STRUCTURE.md.
- Strategy/positioning decisions.
- SEO direction.

## Expected Outputs

- CONTENT_MODEL.md.
- CTA model.
- Metadata draft needs.
- Internal linking model.
- Claim safety notes.
- Localization rules.

## Recommended Steps

1. Define content strategy summary.
2. Define page type models.
3. Define content fields.
4. Define CTA model.
5. Identify metadata requirements.
6. Review claims for safety.
7. Define localization rules.
8. Define internal linking model.
9. Add content QA checklist.

## Codex / Agent Involvement

- ChatGPT Lead Assistant coordinates content planning.
- Content Strategist may develop page models and CTA language.
- Codex should not implement page copy before content structure is approved.

## Tracking Docs Update Rules

- Update CURRENT_STATUS.md after CONTENT_MODEL.md is usable.
- Update NEXT_ACTIONS.md with copy/design/implementation tasks.
- Update ISSUES_LOG.md for missing content or claim risks.
- Update DECISIONS_LOG.md for real content/CTA/localization decisions.

## Completion Criteria

- Content model is usable for implementation.
- CTA model is defined.
- Claim safety notes are documented.
- No launch-critical content gaps are hidden.

## Stop Conditions

- Page structure is not approved.
- Content owner is unclear.
- Claims cannot be verified.
- Language rules are unclear.
- Placeholder content would reach release candidate.

## Handoff Notes

New sessions should inspect CONTENT_MODEL.md, PROJECT_RULES.md, SEO_PLAN.md, CURRENT_STATUS.md, and ISSUES_LOG.md.
